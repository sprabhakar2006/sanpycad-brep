⇆ Exchange: SanPyCAD → SanPyCAD-Brep
Paste a SanPyCAD (mesh app) script on the left, then Convert -- every call that's a real ocad.py function gets prefixed with o. so it keeps calling the exact original mesh-app implementation, unchanged behavior. Calls already qualified (o.foo(...), np.foo(...)), Python builtins, function definitions (def foo(...):), and this app's own show()/color()/echo() helpers (not part of ocad.py) are left bare. Text inside quoted strings/comments is never touched. This only handles the mechanical o. prefix -- functions with no real B-rep purpose here (e.g. fo()/swp()-style OpenSCAD-text-file generation) will still be callable but won't do anything useful; review those by hand.
